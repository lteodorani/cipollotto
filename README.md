# Cipollotto

**Cipollotto** is a CHIP-8 and SCHIP emulator written in **C**, using **SDL** for graphics and input handling.

The project aims to provide a simple and lightweight implementation of the classic CHIP-8 virtual machine, with support for the extended **Super CHIP (SCHIP)** instruction set.

## Features

* CHIP-8 emulation
* Super CHIP (SCHIP) support
* Written in pure C
* Uses SDL for display and input
* Lightweight and minimal design

## Platform Support

Currently, Cipollotto compiles **on Linux**.

## Status

The project is under development and functionality may change as new features are implemented.
